Privacy policy

Vultures Deploy · last updated October 26, 2026

Vultures Deploy is a private tool used by one person, Leonard Pieton, to maintain The Vultures production portal. This policy explains what it accesses in his Google account and why.

What it accesses

With the account owner's permission, Vultures Deploy uses Google's official APIs to:

  • Google Apps Script: read, update, version and publish the portal's own Apps Script projects, and run the portal's built-in maintenance functions (checks and backups).
  • Google Sheets and Google Drive: read and update the portal's spreadsheet, and save backup copies to the portal's backup folder, through the portal's own code.
  • Google Calendar: read the production calendar, as the portal does.

It does not read Gmail, contacts or any files outside what the portal itself uses.

How the data is used

Only to update, check and back up The Vultures production portal. Nothing is used for advertising, analytics or profiling.

Sharing

Data is not sold, rented or shared with anyone. It is not transferred to third parties, except that the tool runs on GitHub's automation service, which processes the deployment steps on the owner's behalf.

Storage and security

  • The access permission is stored only as an encrypted secret in the owner's private GitHub account. It is never published in code or messages.
  • Changes to the live portal run only after the owner approves them.
  • Backups stay in the owner's own Google Drive.

Google API Services User Data Policy

Vultures Deploy's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time at myaccount.google.com/connections by removing "Vultures Deploy".

Contact

Questions about this policy: contact Leonard Pieton at the support email shown on the Vultures Deploy Google sign-in screen.
