Vultures Deploy

A private maintenance tool for The Vultures production portal.

What it does

The Vultures is a small animated comedy series. Its team uses a private production portal built on Google Apps Script and Google Sheets to plan episodes, share work and approve each step.

Vultures Deploy is the tool that maintains that portal. It is used only by the portal's owner, Leonard Pieton. When he approves a change, Vultures Deploy:

  • uploads the new version of the portal's Apps Script code and publishes it;
  • runs automatic checks to confirm the portal still works;
  • backs up the portal's spreadsheet before any data change;
  • keeps a history of every version so a change can be rolled back.

Vultures Deploy is not a public service, there is nothing to sign up for, and it is not used by anyone other than the portal's owner. It never changes anything in production without the owner's explicit approval.
